# 동작 회귀 검사

프로젝트 폴더에서 실행합니다. 앱 실행 자체에는 Node.js나 npm이 필요하지 않습니다.

```powershell
npm.cmd ci --prefix tests
npm.cmd test --prefix tests
```

Node.js 24.15.0과 jsdom 30.0.1에서 검증했습니다. 실제 HTML과 모든 앱 스크립트를 jsdom에 로드하고 API 응답은 가짜 응답으로 대체합니다. API 키나 외부 API 호출은 사용하지 않습니다.

핵심 입력과 접힌 추가 설정, 단계별 화면 전환·후보 섞기·로딩/중지, 검증 중지 후 결과 보존, 캐스트 부분 결과, 재료 관리 모달·중첩 모달·포커스 복원, 이전 추가 요청 병합, 분류별 화면/작업과 초안 복원을 검사합니다. 기존 대화 실패·재전송·중복 요청, 연결 확인 상한과 잘린 출력 복구 검사도 포함합니다. 화면 배치는 아래 별도 브라우저 검사에서 확인하며, 실제 업체 연결과 생성 품질은 검사하지 않습니다.

히스토리 제외는 별도 `chat-history.test.cjs`에서 전송·요약·작업대 반영·재료화·저장/복원을 검사합니다. 프롬프트의 기존 변형 선택을 새 화면에서도 유지하는지 확인합니다. 연결 백업 검사는 가짜 키와 JSON으로 내보내기·가져오기 및 기존 데이터 보존을 확인하며, 실제 키 파일을 만들지 않습니다.

로컬 Chrome 또는 Edge로 실제 화면 크기별 배치를 확인하려면 다음을 실행합니다. 개인 브라우저와 분리된 임시 프로필을 사용하며 실제 API는 호출하지 않습니다.

```powershell
npm.cmd run test:layout --prefix tests
```

다음 항목을 실제 렌더링으로 검사하고 `tests/artifacts/`에 스크린샷을 만듭니다.

- 교신: 1920×1080, 1280×720, 768×1024, 390×844, 360×740에서 입력창 위치·페이지 넘침·설정 접기·토큰 정보와 도구 배치 확인. 긴 입력의 자동 확장·내부 스크롤·삭제 후 축소, 초안 복원과 화면 폭 변경, 과거 메시지 읽기 위치 보존도 검사
- 작업대: 1920×1080/960/920에서 세계·인물·프롬프트 기본 화면의 세로 넘침과 만들기 버튼 노출 확인. 추가 설정을 펼치거나 구상 입력칸을 늘린 경우에는 정상 스크롤 확인
- 반응형 작업대: 320·360·390·768px 폭에서 가로 넘침 없이 두 만들기 방식을 한 줄에 표시하는지 확인. 프롬프트 시작 선택 두 개의 제목 정렬, 재료 제목·개수의 한 줄 배치와 굵기, 재료 접기·관리 모달도 검사
- 연결·내보내기: 가짜 키로 연결 JSON을 만들고 실제 파일 입력으로 복원. 실제 캔버스에서 PNG를 생성하고 한글 카드 메타데이터를 다시 읽어 확인. 연결·양식·기록·로그의 데스크톱/모바일 배치와 서버 없는 `file://` 실행도 확인

Chrome/Edge가 기본 설치 경로에 없으면 `ORRERY_TEST_BROWSER`에 실행 파일 경로를 지정합니다. 실물 기기의 터치·가상 키보드, 업체별 API/CORS, 생성 품질, Safari 저장과 SillyTavern 가져오기 호환은 별도 확인이 필요합니다.
