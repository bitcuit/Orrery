# ORRERY · 세계 · 인물 · 프롬프트

설정집과 캐릭터 카드를 재료로 삼아 세계와 인물, 그리고 그것으로 굴릴 프롬프트를 길러내는 도구입니다.
파일 하나로 돌아갑니다. 설치할 것도, 서버에 올릴 것도 없습니다.

## 쓰는 법

1. `orrery.html`을 더블클릭합니다.
2. **연결** 탭에서 API 키를 넣고, **맨 윗줄의 확인**을 누릅니다. 옆의 점이 초록이면 됩니다.
3. 두 번째 줄에서 **세계 / 인물 / 프롬프트** 중 무엇을 만들지 고릅니다.
4. **작업대** 첫 줄에서 양식을 고릅니다.
5. **재료** 탭에 카드나 설정집을 넣고, 작업대에서 위에서부터 차례로 누릅니다.

두 번째 줄의 분류가 이 도구의 축입니다. 어느 탭에 있든 늘 보이고, 여기서 고른 것에 따라 양식 목록·작업대 단계·기록 필터·대화 상대가 함께 바뀝니다.
양식은 그 분류 안에서 고르는 것이라 작업대 안에 있습니다.
분류를 바꾸면 작업대는 비워지지만 **재료와 기록은 남습니다** — 세계로 만든 것을 인물 재료로 그대로 쓸 수 있습니다.

## 공정

| 단계 | 하는 일 |
|---|---|
| 1 세계 읽기 | 재료를 압축해 규칙·세력·용어·빈틈을 뽑습니다. 한 번 만들면 재사용합니다. |
| 2 별씨앗 | 한 줄짜리 후보를 여러 개 뽑습니다. 둘을 골라 섞을 수 있습니다. |
| 3 확장 | 고른 별씨앗을 카드로 펼칩니다. 칸별로 잠그고 나머지만 다시 굴립니다. |
| 4 검증 | 세계 설정과 어긋난 곳을 찾아 대체 문안을 제안합니다. |

양식에 따라 2단계나 4단계가 통째로 숨는 것이 있습니다. 점검 양식들이 그렇습니다.

## 모드

- **세계에서 사람 뽑기** — 설정집 중심. 그 세계에 살고 있을 법한 인물.
- **맞부딪힐 상대** — 기존 인물을 읽고 그와 어긋나는 다른 인물.
- **여러 명 + 관계망** — 같은 세계에서 여러 명. 서로를 보는 시선은 양쪽이 다릅니다.

이 셋은 **인물 양식에서만** 쓰입니다.

## 양식

분류를 고르면 그 분류의 양식만 보입니다. 양식이 출력 칸과 지시문을 결정합니다.

### 세계
| 양식 | 쓰임새 |
|---|---|
| 세계관 설계 | 키워드나 반쯤 만든 설정에서 세계를 짭니다 |
| 압축 소개본 | 처음 읽는 사람에게 소개하는 압축본. 확인된 사실과 소문·추론을 구분 |
| 상세 안내서 | 설정집 형태. 작동 원리·대가·한계·실패까지 |
| 세계 점검 | 살아 있는 곳·토대·빈틈·모순·생활의 질감·흔한 배치를 짚고 문안을 제안 |
| 프로필 양식 설계 (JSON) | **이 세계 전용 인물 양식을 JSON으로 뽑습니다** |

### 인물
| 양식 | 쓰임새 |
|---|---|
| 기본 카드 | 이름·외모·성격·말투·배경·비밀·첫 대사 |
| 창작 엔진 (풀 시트) | 모든 설정에 원인을 요구. 이름을 지우면 남에게 붙는 문장을 걸러냄 |
| 설정집 프로필 (압축형) | 명사형 어미, 은유 없음, 예시 대사 없음 |
| 첫 만남 (그리팅) | 카드에 넣을 첫 장면. `{user}`의 말과 행동은 쓰지 않음 |
| 성향 프로토콜 (성인 · 18+) | 심리 여섯 축을 읽고 성적 기질을 도출 |
| 인물 점검 | 살아 있는 곳·분화·인과·목소리·굴러가는가·`{user}` 자리를 짚음 |

### 프롬프트
| 양식 | 쓰임새 |
|---|---|
| 프롬프트 생성기 | 만들고 싶은 프롬프트를 설명하면 완성된 프롬프트를 짜줌 |
| 롤플레이 프롬프트 | 인물 하나로 굴릴 묶음. 지시문·문체·첫 장면·상황 변주 |
| 프롬프트 점검 | 살아 있는 곳·판정 가능성·규칙 충돌·빠진 통제·출력 형식을 짚음 |

**점검** 양식은 분류마다 따로 있습니다. 만든 것을 재료 탭에 넣고 돌리면 됩니다.
세 점검 양식 모두 **살아 있는 곳** 칸이 먼저 나옵니다 — 어디를 건드리면 안 되는지부터 봅니다.
**프로필 양식 설계 (JSON)** 는 세 분류 어디서든 보입니다.

## 한 번에 만들기 · 단계별로

작업대 위쪽에 **한 번에 만들기**가 있습니다. API를 **1회만** 부르고 끝냅니다.
아래 단계별 공정은 그대로 남아 있습니다. 상황에 따라 골라 쓰세요.

| | 한 번에 | 단계별 |
|---|---|---|
| API 호출 | 1회 | 3~4회 |
| 별씨앗 고르기 | 없음 (모델이 알아서) | 후보를 보고 고르고 섞음 |
| 검증 | 없음 (나중에 따로 가능) | 자동 |
| 긴 재료 | 요약 없이 통째로 → 상한 넘기 쉬움 | 요약해서 돌리므로 안전 |
| 어울리는 때 | 재료가 작을 때, 빨리 뽑아볼 때 | 재료가 클 때, 결과를 다듬을 때 |

몇 번 부르는지는 버튼 바로 아래에 그때그때 적혀 있습니다.
한 번에 만든 뒤에도 칸 잠금·다시 굴리기·검증·물어보기는 그대로 씁니다.

## 요청 칸

작업대 위쪽, 양식 줄 아래에 있습니다. 여기 적은 내용은 **모든 단계**에 함께 전달됩니다.

- 분류마다 따로 기억합니다. 세계에 적은 요청이 인물 작업에 따라오지 않습니다
- 예: `전투보다 생활감 위주로` / `30대 이상` / `고유명사는 짧게` / `존댓말로`

## 분류마다 다른 것

| | 세계 | 인물 | 프롬프트 |
|---|---|---|---|
| 1단계 이름 | 세계 읽기 | 재료 읽기 | 요구 정리 |
| 구상 칸 | 재료 없이 이것만으로 시작 가능 | 원하는 인물 방향 | **주 입력** — 무엇을 만들 프롬프트인가 |
| 재료 | 대부분 필수 | 절반은 없어도 됨 | 절반은 필수 |
| 읽은 요약 | 분류마다 **따로 보관** | | |

칸 이름은 세 분류 모두 **구상**으로 같고, 아래 안내문과 예시만 달라집니다.
양식을 고르면 그 양식이 재료를 필요로 하는지 바로 아래에 표시됩니다.
읽은 요약은 분류마다 따로 보관되므로, 세계에서 읽은 요약이 인물 작업에 잘못 딸려가지 않습니다.

## 세계 전용 양식 만들기

세계마다 필요한 칸이 다릅니다. 식별자가 있는 세계, 누적 수치가 있는 세계, 계약 관계가 중심인 세계는 일반 카드 양식으로 담기지 않습니다.

1. **세계** 분류에서 **프로필 양식 설계 (JSON)** 를 고릅니다.
2. 재료 탭에 설정집을 넣고 돌립니다.
3. 결과에 칸 정의 JSON이 나옵니다. 마음에 안 들면 그 칸을 직접 고치면 됩니다.
4. 아래 **이 양식 등록하기**를 누르면 인물 분류에 새 양식으로 들어갑니다.
5. 그 양식으로 바로 인물을 뽑습니다.

설계기가 함께 뽑는 **작성 규칙**과 **검사 항목**은 등록할 때 지시문에 자동으로 끼워 넣습니다.
식별자를 누구 것으로 볼지, 헷갈리는 용어를 어떻게 구분할지 같은 것이 그 세계의 규칙으로 박힙니다.

### 이어 붙이기

결과물 아래 **재료로 넣기**를 누르면 방금 만든 것이 재료 탭으로 들어갑니다.
세계관 → 인물 → 롤플레이 프롬프트로 이어 만들거나, 만든 것을 점검 양식에 바로 물릴 수 있습니다.

세계관 양식에는 **로어북으로 뽑기**가 따로 있습니다. 세계 문서를 항목별로 쪼개 파일로 내려받는 동시에 재료 탭에도 넣습니다.
SillyTavern 월드인포 형식이라 다른 데서도 그대로 씁니다.

## 물어보기

무언가 만들고 나면 아래에 물어보는 칸이 생깁니다.

- **설계 상담역** — 설계자의 눈으로 답합니다. 문제를 어떻게 풀지 선택지를 줍니다
- **당사자 본인** — 그 인물로서, 또는 그 세계에 사는 사람으로서 답합니다

답에 고칠 문안이 딸려 오면 **이 문안으로 바꾸기**로 바로 반영됩니다.
검증 단계에서 나온 지적에는 **이 문제 어떻게 할까?** 단추가 붙어 있어 그대로 질문으로 넘어갑니다.

## 기록

만든 것은 **자동으로** 기록 탭에 남습니다. 따로 저장할 필요가 없습니다.
작업대 아래의 **고정하기**를 누르면 ★가 붙은 채로 남습니다.

- **★** 를 켜두면 오래돼도 지워지지 않습니다. 200개가 넘으면 고정 안 한 오래된 것부터 정리됩니다
- 이름을 눌러 바꾸고, 검색과 분류로 찾습니다
- **불러오기**로 작업대에 되돌리면 그 양식으로 자동 전환됩니다
- 글(마크다운) · JSON · PNG로 내보낼 수 있습니다

## 대화

공정은 형식이 정해져 있습니다. 형식 없이 물어보고 싶을 때 **대화** 탭을 씁니다.

- **상대 역할** — 세계관 상담역 / 인물 상담역 / 프롬프트 상담역 / 냉정한 평가자 / 역할 없음
- 분류를 바꾸면 상담역은 따라 바뀝니다. **평가자와 역할 없음은 그대로 둡니다**
- **역할 프롬프트 편집** — 역할에게 내릴 지시문을 직접 쓸 수 있습니다. 기본 프롬프트를 펼쳐 보고, 언제든 되돌립니다
- **같이 보낼 것** — 재료 · 세계 요약 · 지금 만든 것을 체크한 만큼만 딸려 갑니다. 아래에 분량이 표시됩니다
- **이 대화를 재료로** — 주고받은 내용을 재료 탭에 넣습니다. 대화로 정한 걸 그대로 공정에 물릴 수 있습니다

Ctrl+Enter로 보냅니다.

## 프롬프트 고치기

맨 윗줄 오른쪽의 **양식**에서 각 공정의 지시문과 출력 칸을 직접 고칩니다.
`{{이름}}` 자리는 실행할 때 값으로 바뀝니다. 쓸 수 있는 값은 맨 아래에 적혀 있습니다.

**출력 칸**에 적은 것이 곧 카드의 칸이자 잠금·재굴림 단위입니다. 칸을 늘리거나 지우면 프롬프트가 알아서 따라갑니다.

**공통 지시문**은 모든 공정 맨 앞에 순서대로 들어갑니다. 구획별로 껐다 켤 수 있습니다.

SillyTavern 챗컴플리션 프리셋은 양식 줄 오른쪽의 **가져오기** 단추로 읽어들입니다(Orrery 양식 파일과 자동 판별).
지시문 블록만 뽑아 **공통 지시문**으로 들어오는 방식이라, 공정 자체는 그대로 남습니다.

## 연결 설정

연결마다 따로 조정할 수 있습니다. 비워두면 양식에 적힌 값을 씁니다.

| 항목 | 설명 |
|---|---|
| 응답 토큰 상한 | 한 번에 받을 최대 길이. 결과가 중간에 끊기면 올리세요 |
| 컨텍스트 상한 | 모델이 받을 수 있는 총량. 넘으면 보내기 전에 막고 알려줍니다 |
| temperature | 낮추면 안정적, 올리면 변화가 큽니다 |
| top_p | 비워두면 보내지 않습니다 |

**모델 목록 받기**를 누르면 그 업체가 주는 모델 이름이 입력칸 후보로 채워집니다.
재료가 많아 상한을 넘으면 **세계 읽기**를 먼저 하세요. 요약본으로 돌리면 분량이 크게 줄어듭니다.

## 연결이 안 될 때

대부분의 연결은 파일에서 바로 열어도 됩니다.
특정 연결만 막힌다면 그 업체가 브라우저 직접 호출을 거부하는 것이니, OpenRouter처럼 다른 연결을 만들어 쓰세요.

여러 곳이 한꺼번에 막힌다면 이 파일이 있는 폴더에서 아래를 실행한 뒤
`http://localhost:8777/orrery.html` 로 여세요.

```
python -m http.server 8777
```

## 알아둘 것

- API 키는 **이 브라우저에만** 저장됩니다. 공용 PC에서는 쓰지 마세요.
- 사파리는 파일에서 열었을 때 저장을 막습니다. 이때는 **로그** 탭에만 조용히 실패가 남으므로, 사파리를 쓴다면 **연결 → 설정 내보내기**로 미리 백업해 두세요.
- 브라우저 데이터를 지우면 보관함도 같이 지워집니다.
- 생성 도중 **Esc**를 누르면 멈춥니다.

"보낸 지시문 전문까지"를 켜면 실제로 나간 프롬프트도 함께 남습니다.
