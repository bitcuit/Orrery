# ORRERY · 세계 · 인물 · 프롬프트

현재 버전: **v1.0.0** (첫 공개 배포)

설정집과 캐릭터 카드를 재료로 삼아 세계와 인물, 그리고 그것으로 굴릴 프롬프트를 길러내는 도구입니다.
설치나 빌드 없이 정적 파일 묶음으로 돌아갑니다. 폴더 구조를 유지한 채 `index.html`을 열면 됩니다.

## 쓰는 법

1. `index.html`을 더블클릭합니다.
2. 환영 화면이나 두 번째 줄에서 **세계 / 인물 / 프롬프트** 중 무엇을 만들지 고릅니다.
3. 작업대 위쪽에서 **양식과 작업 방향**을 고르고 **구상**에 만들 내용과 지킬 조건을 함께 적습니다.
4. 카드나 설정집이 있으면 **재료 추가·관리**로 창을 열어 넣고 사용할 항목을 고릅니다. 창을 닫으면 작업대로 돌아오며 선택한 재료 목록은 펼치거나 접을 수 있습니다.
5. **만들기**를 누릅니다. 처음 연결이 필요하면 버튼이 **연결 설정하고 만들기**로 표시되고 연결 화면을 엽니다. 구상은 그대로 남으니 업체·키·모델을 설정한 뒤 같은 분류의 작업대로 돌아와 **만들기**를 누르세요. 설정 후 자동으로 생성하지는 않습니다.
6. 생성 중에는 진행 상태와 **요청 중지**가 있는 로딩 화면을 보여줍니다. 한 번에 만들기는 완성 결과로, 단계별 만들기는 정리 확인 → 후보 선택 → 결과 화면으로 이동합니다. **입력으로 돌아가기**로 입력을 고치거나 기존 작업을 다시 열 수 있습니다.

입력 아래의 **한 번에 만들기 / 단계별로 만들기** 카드에 각 방식의 효과와 기본 API 호출 횟수를 표시합니다. 쉬운 모드에서도 두 방식을 선택할 수 있고 기존 선택을 유지합니다. **만들기** 버튼은 입력 상자 밖 오른쪽에 있으며, 출력 언어·톤 같은 추가 설정(Advanced)은 필요할 때 펼칩니다. 연결을 따로 시험하려면 맨 윗줄의 **확인**을 누르세요. 짧은 API 테스트 호출이 1회 나갑니다.

두 번째 줄의 분류가 이 도구의 축입니다. 어느 탭에 있든 늘 보이고, 여기서 고른 것에 따라 양식 목록·작업대 단계·기록 필터·대화 상대가 함께 바뀝니다.
양식은 그 분류 안에서 고르는 것이라 작업대 안에 있습니다.
분류를 바꾸면 각 분류의 **구상·후보·결과·잠금·문답·캐스트·최종본**을 보관했다가 돌아올 때 복원합니다. 재료와 기록은 함께 쓰므로 세계로 만든 것을 인물 재료로 그대로 쓸 수 있습니다. 모바일 내비에는 **재료·세계·인물·프롬프트·대화·기록**처럼 기능 이름이 표시됩니다.

세계 작업대의 **추가 설정**에서 **세계 분위기(가볍게 / 균형 있게 / 무겁게)**와 **설정 밀도(간결 / 보통 / 상세)**를 따로 고릅니다. 기본값은 가볍게·보통이며, 밀도는 구체화 정도만 조절하고 글자 수를 지정하지 않습니다. 분량을 지정하지 않으면 구상에 필요한 만큼 작성합니다. 구상에 분량을 적거나 **분량 직접 조정**에서 공백 포함 400~12,000자의 목표를 입력할 수 있습니다. 실제 생성 분량을 보장하는 제한은 아니며, 결과를 강제로 자르지 않습니다. 명시적인 구상과 원본 사실을 우선하고, 성인 요소 허용만으로 어두운 설정을 추가하지 않습니다. 이 설정은 두 생성 방식에 적용되고 저장·백업됩니다.

## 파일 구성

- `index.html` — 화면 뼈대
- `styles.css` — 화면 모양
- `prompts.js` — 기본 공통 지시문
- `assets/` — 배경 이미지
- `js/` — 저장·재료·제작·대화·기록·연결 기능

`js/` 안의 파일은 `index.html`에 적힌 순서대로 읽습니다. 빌드 도구나 개발 서버는 필요하지 않습니다.

개발용 동작 검사와 Chrome/Edge 화면 배치 검사는 [tests/README.md](tests/README.md)를 참고하세요. 실제 업체 API 연결·생성 품질과 실물 기기의 터치·가상 키보드 동작은 별도 확인이 필요합니다.

## 공정

| 단계 | 하는 일 |
|---|---|
| 1 설계 준비·재료 정리·요구 정리 | 구상과 선택한 재료를 정리해 확정된 것·빈틈·질문을 눈으로 확인합니다. |
| 2 별씨앗 | 한 줄짜리 후보를 여러 개 뽑습니다. 둘을 골라 섞을 수 있습니다. |
| 3 확장 | 고른 별씨앗으로 결과를 만듭니다. 칸별로 잠그고 나머지만 다시 씁니다. |
| 4 검증 | 세계 설정과 어긋난 곳을 찾아 대체 문안을 제안합니다. |

양식에 따라 별씨앗이나 검증이 숨습니다. 숨긴 단계의 빈 번호는 남기지 않고 뒤 단계를 앞으로 당겨 표시합니다. 별씨앗이 없는 양식도 정리 내용을 먼저 확인한 뒤 **결과 만들기**를 누릅니다. 검증은 완성 결과 화면 안에서 확인합니다.

## 작업 방향

- **세계** — 새 세계 만들기 / 기존 세계 다듬기
- **인물** — 세계에서 사람 뽑기 / 기존 인물 다듬기 / 맞부딪힐 상대 / 여러 명 + 관계망
- **프롬프트** — 새 프롬프트 만들기 / 기존 프롬프트 수정. 수정 목적은 **추가 설정**에서 같은 용도 다듬기 / 다른 용도 바꾸기로 고릅니다

기존 것을 다듬을 때는 **추가 설정**에서 **균형 있게 / 단순하게 / 자세하게 / 다시 설계** 중 하나를 고릅니다. 기본값인 균형 있게는 무조건 내용을 추가하지 않고 중복·장식을 덜어낸 뒤 실제로 필요한 빈틈만 보완합니다. 단순하게는 삭제·통합을, 자세하게는 작동 조건과 인과의 구체화를, 다시 설계는 핵심을 지키면서 묶음과 순서를 재구성하는 작업을 우선합니다. 이 선택은 세계·인물·프롬프트별로 따로 기억됩니다.

## 양식

분류를 고르면 그 분류의 양식만 보입니다. 양식이 출력 칸과 지시문을 결정합니다.

### 세계
| 양식 | 쓰임새 |
|---|---|
| 세계관 설계 | 키워드나 반쯤 만든 설정에서 세계를 짭니다 |
| 압축 소개본 | 처음 읽는 사람에게 소개하는 압축본. 확인된 사실과 소문·추론을 구분 |
| 상세 안내서 | 설정집 형태. 작동 원리·대가·한계·실패까지 |
| 세계 점검 | 살아 있는 곳·토대·빈틈·모순·생활의 질감·흔한 배치를 짚고 문안을 제안 |
| 프로필 양식 설계 (JSON) | **이 세계 전용 인물 양식을 JSON으로 뽑습니다** |

### 인물
| 양식 | 쓰임새 |
|---|---|
| 기본 카드 | 이름·외모·성격·말투·배경·비밀·첫 대사 |
| 창작 엔진 (풀 시트) | 모든 설정에 원인을 요구. 이름을 지우면 남에게 붙는 문장을 걸러냄 |
| 설정집 프로필 (압축형) | 명사형 어미, 은유 없음, 예시 대사 없음 |
| 첫 만남 (그리팅) | 카드에 넣을 첫 장면. `{user}`의 말과 행동은 쓰지 않음 |
| 성향 프로토콜 (성인 · 18+) | 심리 여섯 축을 읽고 성적 기질을 도출 |
| 인물 점검 | 살아 있는 곳·분화·인과·목소리·굴러가는가·`{user}` 자리를 짚음 |

### 프롬프트
| 양식 | 쓰임새 |
|---|---|
| 프롬프트 생성기 | 만들고 싶은 프롬프트를 설명하면 완성된 프롬프트를 짜줌 |
| 롤플레이 프롬프트 | 인물 하나로 굴릴 묶음. 지시문·문체·첫 장면·상황 변주 |
| OOC 지시문 | 보고 싶은 장면을 적으면 롤플레잉 AI에 바로 붙일 OOC를 씀. 형식을 골라 형식마다 하나씩, 역할 반전 버전도 함께 |
| 프롬프트 점검 | 살아 있는 곳·판정 가능성·규칙 충돌·빠진 통제·출력 형식을 짚음 |

**점검** 양식은 분류마다 따로 있습니다. 만든 것을 재료 탭에 넣거나 작업대의 구상 칸에 원문을 붙여 돌리면 됩니다.
세 점검 양식 모두 **살아 있는 곳** 칸이 먼저 나옵니다 — 어디를 건드리면 안 되는지부터 봅니다.
**프로필 양식 설계 (JSON)** 는 세 분류 어디서든 보입니다.

## 한 번에 만들기 · 단계별로

구상·요청과 재료 아래에서 **단계별로 만들기 / 한 번에 만들기**를 고릅니다.
한 번에 만들기는 입력 → 로딩 → 결과로 이동합니다. 일반 결과는 API **기본 1회**로 만들며, 응답이 잘리거나 형식이 맞지 않으면 복구를 위해 추가 호출할 수 있습니다. 단계별 만들기는 입력 → 정리 확인 → 후보 선택 → 결과를 한 화면씩 보여줍니다.

| | 한 번에 | 단계별 |
|---|---|---|
| API 호출 | 기본 1회 | 양식에 따라 기본 2~4회 |
| 별씨앗 고르기 | 없음 (모델이 알아서) | 후보를 보고 고르고 섞음 |
| 검증 | 없음 (나중에 따로 가능) | 켠 경우 자동, 양식에 따라 생략 |
| 긴 재료 | 요약 없이 통째로 → 상한 넘기 쉬움 | 요약해서 돌리므로 안전 |
| 어울리는 때 | 재료가 작을 때, 빨리 뽑아볼 때 | 재료가 클 때, 결과를 다듬을 때 |

기본 호출 횟수와 각 방식의 효과는 선택 카드 안에서 바로 비교합니다. 설명은 짧은 명사형으로 표시하고 좁은 화면에서도 두 카드를 나란히 둡니다. 생성 버튼 옆 별도 도움말은 없습니다. 여러 명을 만드는 캐스트는 인원에 따라 호출 횟수가 늘어나며, 선택 카드의 안내도 함께 바뀝니다. 관계 만들기는 별도로 실행합니다.

**입력으로 돌아가기**는 구상·요청, 재료 선택과 기존 결과를 보존합니다. 입력을 수정한 뒤 **결과 다시 보기**를 누르면 API 호출 없이 기존 결과를 표시합니다. 완성 전에는 **진행 중인 작업 보기**로 돌아갑니다. 수정한 입력으로 새 결과를 생성하려면 **다시 만들기**를 누르세요. 실패하거나 중지해도 입력과 이미 만든 결과를 유지합니다.

입력·정리·후보·결과·캐스트 중 어느 화면을 보고 있었는지도 분류별로 기억합니다. 새로고침 뒤 이전 작업 복구를 선택하면 그 화면으로 돌아옵니다.
한 번에 만든 뒤에도 칸 잠금·다시 쓰기·검증·결과에 질문하기는 그대로 씁니다. 작업대에서 API를 호출하면 큰 로딩 화면에 현재 처리 상태, 실제 요청 차수와 **요청 중지**가 나타납니다.

요청 중에는 분류·양식·작업 입력을 바꾸거나 다른 생성을 동시에 실행할 수 없습니다. 요청이 끝나거나 중지된 뒤 다시 변경할 수 있습니다.

세부 기능은 기본으로 접힌 **추가 도구** 안에 모았습니다. 일괄 다시 쓰기·잠금·검증·질문·최종 출력이 필요할 때 펼치세요. 결과 내용과 **고정하기·글로 복사·글로 내려받기**는 바로 보이고, 나머지 내보내기는 **다른 형식·재료로**에서 고릅니다. **쉬운 모드**에서도 추가 설정과 도구를 펼칠 수 있습니다. 잘린 출력은 **이어서 만들기**를 자동으로 펼쳐 복구할 수 있게 합니다.

단계별 만들기는 정리 화면에서 내용을 확인한 뒤 다음 버튼으로 후보를 만듭니다. 후보 하나를 고르면 **이 후보로 만들기**, 둘을 고르면 **고른 둘 섞기**를 사용할 수 있습니다. 선택하거나 섞는 동안에는 후보 화면에 머물며, 만들기를 눌러야 결과로 넘어갑니다. 이전에 만든 단계는 상단 단계선으로 다시 볼 수 있습니다.

별씨앗의 **후보 조정**에 추가 지시를 적고 **후보 다시 제안** 또는 **고른 둘 섞기**를 누를 수 있습니다. 다시 제안은 선택한 후보를, 선택이 없으면 현재 후보 전체를 참고합니다. 지문을 비우면 기본 동작으로 실행합니다. 실패·중지 시 기존 후보를 유지하며, 지문은 분류별 작업과 함께 복구됩니다. 생성된 후보의 조정 지시는 최종 생성에도 전달합니다.

세계·인물·프롬프트 모두 별씨앗의 **다음 제안 방식**에서 **한 줄 후보 / 키워드 조합**을 고를 수 있습니다. 키워드 조합은 짧은 단어·구를 버튼으로 제안하며, 여러 개를 골라 **고른 키워드로 만들기**로 넘깁니다. 선택한 키워드의 조합 자체에는 API를 호출하지 않습니다. 방식만 바꾸면 현재 후보는 유지되고, 제안 버튼을 눌렀을 때 새 방식으로 생성합니다. 선택 방식과 키워드는 저장·복구됩니다.

세 작업대 모두 넓은 화면에서는 입력으로 돌아가는 화살표를 작업대 제목 왼쪽에, 현재 양식명을 제목 오른쪽에 표시합니다. 제목 위치는 입력 화면과 같습니다.

**여러 명 + 관계망**은 생성한 인물 목록을 별도 결과 화면으로 보여줍니다. 인물을 열어 개별 결과를 편집하고 캐스트 목록으로 돌아갈 수 있습니다. 중간에 멈춰도 그때까지 완성된 인물은 남습니다.

한 번에 만들기는 **선택한 재료나 구상 중 하나만 있어도** 실행됩니다. 재료가 있다면 구상은 선택 사항이며, 비워두면 고른 재료만 사용합니다.

## 이어서 만들기

결과가 응답 길이 때문에 중간에 끊기면 Orrery가 먼저 끊긴 JSON을 자동으로 한 번 이어받습니다. 그래도 끝나지 않으면 읽을 수 있는 칸까지 작업대에 복구하고 **출력이 중간에 끊겼습니다**라고 표시합니다.

결과 아래 **이어서 만들기**는 세계·인물·프롬프트에서 모두 쓸 수 있습니다. 지시를 비우고 누르면 잘린 칸이나 마지막 칸부터 자연스럽게 잇고, `배경 칸을 관계 변화까지 더 써줘`처럼 추가 지시를 적으면 그 방향의 새 내용만 기존 결과 뒤에 붙입니다. 기존 내용은 다시 쓰거나 덮어쓰지 않으며, 이어 쓴 결과와 기록은 임시 작업·성도 기록·전체 백업에 함께 남습니다. `Ctrl+Enter`로도 실행할 수 있습니다.

## 최종 출력 만들기

완성 결과 아래의 접이식 **최종 출력 만들기**는 세계·인물·프롬프트에서 공통으로 씁니다. 작업대의 원본 결과는 그대로 두고 아래 항목을 골라 별도의 최종본을 만듭니다. API 호출은 **1회가 기본**이며, 응답이 잘리거나 형식이 깨지면 자동 이어받기·재시도가 추가될 수 있습니다.

- **번역** — 원본 언어와 번역 언어를 직접 적습니다. 한국어→영어뿐 아니라 원하는 언어 조합을 쓸 수 있습니다
- **핵심 유지·토큰 최적화** — 설정·관계·규칙·금지·제약은 보존하고 군더더기와 중복을 줄입니다
- **YAML로 정리** — 기존 칸 구조와 키를 유지한 유효한 YAML로 만듭니다
- **약 N자로 요약** — 핵심을 남기고 지정한 글자 수에 가까운 길이로 줄입니다. 모델 출력 특성상 정확히 고정된 글자 수가 아니라 목표치입니다
- **원본 언어 뜻풀이 함께** — 번역·축약된 최종본이 원본 언어로 정확히 무슨 뜻인지 함께 만듭니다. 원문을 그대로 복원하는 것이 아니라 **변환된 최종본의 역번역**이라 빠지거나 달라진 뜻을 확인할 수 있습니다
- **마지막 추가 요청** — 위 옵션을 적용한 뒤 마지막에 반영할 문체·표기·출력 조건을 적습니다. 체크 없이 이 요청만으로도 최종본을 만들 수 있으며, 세계·인물·프롬프트별로 따로 기억하고 새 작업을 시작하면 비웁니다

뜻풀이는 만든 뒤에도 **보기/숨기기**로 접을 수 있습니다. 최종 출력 응답이 자동 이어받기 뒤에도 끝나지 않으면 읽힌 부분까지 먼저 복구하고 **잘린 부분 이어서**를 강조합니다. 평소에도 결과 옆 **이어서**를 눌러 기존 내용은 유지한 채 최종본과 뜻풀이의 새 부분만 계속 붙일 수 있습니다.

최종본에는 글자 수 기반의 대략적인 전후 토큰 수와 감소율, 목표·실제 글자 수, 이어 쓴 횟수가 표시되고, 원본 결과를 나중에 고치면 다시 만들어야 한다는 표시가 붙습니다. 최종본·뜻풀이·이어쓰기 기록은 현재 작업·기록·전체 백업에 함께 저장됩니다.

## 구상·요청과 재료

만들고 싶은 내용과 지켜야 할 조건을 **구상** 한 칸에 함께 적습니다. 예전 추가 요청에 저장된 내용은 각 분류의 구상 뒤에 **추가 조건:**으로 합쳐 보관합니다. 완성 결과를 변환하는 **최종 출력 만들기**의 마지막 추가 요청은 별도로 유지합니다.
구상 입력칸은 기본 두 줄 높이이며 필요하면 아래로 늘릴 수 있습니다. **사용할 재료**와 선택 개수는 같은 줄에 표시하고 제목만 굵게 구분합니다. **재료 추가·관리**는 성운 밖에서 재료 관리 창을 열고, 닫으면 현재 작업으로 돌아옵니다. 선택한 재료 목록은 기본으로 접어 두고 필요할 때 펼칩니다. 재료 선택은 두 생성 방식에 똑같이 적용됩니다.

- 분류마다 따로 기억합니다. 세계에 적은 요청이 인물 작업에 따라오지 않습니다
- 입력 예시도 현재 분류에 맞춰 바뀝니다. 세계는 규칙·생활 방향, 인물은 나이·말투·역할, 프롬프트는 원하는 문체와 감정선을 만드는 프롬프트를 예로 보여줍니다

## 분류마다 다른 것

| | 세계 | 인물 | 프롬프트 |
|---|---|---|---|
| 1단계 이름 | 설계 준비 | 재료 정리 | 요구 정리 |
| 구상 칸 | 재료 없이 이것만으로 시작 가능 | 원하는 인물 방향 | **주 입력** — 무엇을 만들 프롬프트인가 |
| 재료 | 선택 — 구상만으로 시작 가능 | 선택 — 구상만으로 시작 가능 | 선택 — 구상이 주 입력 |
| 정리한 내용 | 분류마다 **따로 보관** | | |
| 성운 재료 | 구상 아래 **사용할 재료**에서 이번 작업에 쓸 항목을 바로 선택 | | |

칸 이름은 세 분류 모두 **구상**이며 예시만 달라집니다. 중복 안내문과 ‘선택’ 표시는 제거했습니다. 프롬프트는 **새 프롬프트 만들기 / 기존 프롬프트 수정**으로 시작하고, 수정 목적은 **추가 설정**에서 같은 용도 다듬기 / 다른 용도 바꾸기로 고릅니다. 기존 변형 모드의 선택은 유지합니다.
구상·요청뿐 아니라 후보 선택·결과·잠금·문답·캐스트·최종본과 현재 화면도 세계·인물·프롬프트별로 복원됩니다. 작업대 오른쪽 위 **새 작업**은 확인 후 현재 분류의 입력과 제작 진행 상태를 비웁니다. 다른 분류의 작업과 재료·기록은 남깁니다.
재료가 비어 있어도 성운의 바로가기나 위 분류 버튼으로 어느 작업대든 들어갈 수 있습니다. 새로 만드는 양식은 구상만으로 시작할 수 있고, 기존 자료를 다듬거나 변형·점검하는 양식은 읽을 원본이 필요하다는 안내가 표시됩니다.
정리한 내용은 분류마다 따로 보관되므로, 세계의 설계 준비가 인물 작업에 잘못 딸려가지 않습니다.
성운에서 재료를 수정하거나 선택을 바꾸면 기존 정리본에 다시 정리 권장 표시가 붙습니다.
재료의 **수정**을 열면 처음 불러온 원본과 비교하거나 원본으로 되돌릴 수 있습니다. 오른쪽 위 **X**는 창을 닫으며 이번 편집을 적용하지 않고, 아래 **수정**을 눌러야 반영됩니다. **복제**는 현재 수정본을 별도 재료로 만들고, 휴지통 아이콘은 재료를 삭제합니다. 다른 화면에서도 X는 닫기에만 쓰고 삭제는 휴지통으로 표시합니다.
텍스트를 직접 붙여넣을 때는 재료 이름과 함께 **쓸 곳(세계·인물·프롬프트, 복수 선택)**과 쉼표로 구분한 **태그**를 적을 수 있습니다. 이름을 비우면 본문의 첫 줄로 자동 생성합니다. 파일로 넣은 캐릭터 카드는 인물, 로어북은 세계로 자동 분류되며 수정 화면에서 바꿀 수 있습니다. 목록의 쓸 곳 배지는 모두 같은 회청색을 사용하며, 파일 형식은 수정 화면에서 확인합니다.
불러온 재료는 즐겨찾기 여부와 상관없이 브라우저에 저장되어 새로고침하거나 다시 열어도 남습니다. 위 검색칸은 재료 이름뿐 아니라 쓸 곳·태그(`#태그` 검색 가능)·캐릭터 필드·로어북 항목·텍스트 본문까지 찾습니다. 태그를 누르면 그 태그가 붙은 전체 재료를 바로 검색하고, 검색칸 왼쪽에서는 쓸 곳으로 거를 수 있습니다.
재료 카드의 **별표**는 삭제 보호와 폴더 분류에 씁니다. 먼저 **즐겨찾기**를 연 뒤, 그 안에서 **모두 / 미분류 / 폴더 이름**으로 나눠 봅니다. 폴더가 많으면 보이는 스크롤바 없이 가로로 끌거나 밀어서 넘깁니다. 폴더는 만들기·이름 바꾸기·삭제가 가능하며, 폴더만 삭제하면 안의 재료는 지워지지 않고 **미분류**로 옮겨집니다.
**즐겨찾기 외 전체 삭제**는 별표가 없는 재료만 한꺼번에 지웁니다.
작업대의 **사용할 재료**에서는 현재 세계·인물·프롬프트 분류와 맞는 성운 재료를 위에 `추천`으로 보여주지만, 다른 재료를 자동으로 빼지는 않습니다.

## 세계 전용 양식 만들기

세계마다 필요한 칸이 다릅니다. 식별자가 있는 세계, 누적 수치가 있는 세계, 계약 관계가 중심인 세계는 일반 카드 양식으로 담기지 않습니다.

1. **세계** 분류에서 **프로필 양식 설계 (JSON)** 를 고릅니다.
2. 재료 탭에 설정집을 넣고 돌립니다.
3. 결과에 칸 정의 JSON이 나옵니다. 마음에 안 들면 그 칸을 직접 고치면 됩니다.
4. 아래 **이 양식 등록하기**를 누르면 인물 분류에 새 양식으로 들어갑니다.
5. 그 양식으로 바로 인물을 뽑습니다.

설계기가 함께 뽑는 **작성 규칙**과 **검사 항목**은 등록할 때 지시문에 자동으로 끼워 넣습니다.
식별자를 누구 것으로 볼지, 헷갈리는 용어를 어떻게 구분할지 같은 것이 그 세계의 규칙으로 박힙니다.

### 이어 붙이기

결과물 아래 **재료로 넣기**를 누르면 방금 만든 것이 재료 탭으로 들어갑니다.
세계관 → 인물 → 롤플레이 프롬프트로 이어 만들거나, 만든 것을 점검 양식에 바로 물릴 수 있습니다.

세계관 양식에는 **로어북으로 뽑기**가 따로 있습니다. 세계 문서를 항목별로 쪼개 파일로 내려받는 동시에 재료 탭에도 넣습니다.
SillyTavern 월드인포 형식이라 다른 데서도 그대로 씁니다.

## 결과에 질문하기

무언가 만들고 나면 아래에 물어보는 칸이 생깁니다.

- **설계 상담역** — 설계자의 눈으로 답합니다. 문제를 어떻게 풀지 선택지를 줍니다
- **당사자 본인** — 그 인물로서, 또는 그 세계에 사는 사람으로서 답합니다

답에 고칠 문안이 딸려 오면 **이 문안으로 바꾸기**로 바로 반영됩니다.
검증 단계에서 나온 지적에는 **이 문제 어떻게 할까?** 단추가 붙어 있어 그대로 질문으로 넘어갑니다.

## 기록

만든 것은 **자동으로** 기록 탭에 남습니다. 따로 저장할 필요가 없습니다.
작업대 아래의 **고정하기**를 누르면 ★가 붙은 채로 남습니다.

불러온 재료는 늘 저장됩니다. **제작 공정**은 다른 분류에 보관한 중간 작업과 함께 별도로 임시 보관되며, 다음에 열면 **이전 작업물을 불러올까요?**라고 묻습니다. **고정하기** 또는 캐스트의 **기록에 넣기**를 눌러도 중간 작업 복구를 위해 임시본을 유지합니다.

- **★** 를 켜두면 오래돼도 지워지지 않습니다. 기록은 최대 200개이며, 넘으면 고정 안 한 오래된 것부터 정리하고 화면에 알립니다
- 이름을 눌러 바꾸고, 검색과 분류로 찾습니다
- **불러오기**로 작업대에 되돌리면 그 양식으로 자동 전환됩니다
- 글(마크다운) · JSON · PNG로 내보낼 수 있습니다
- 작업대로 불러오면 저장해 둔 최종본과 원본 언어 뜻풀이도 함께 돌아옵니다

## 대화

공정은 형식이 정해져 있습니다. 형식 없이 물어보고 싶을 때 **대화** 탭을 씁니다.

대화창은 여러 개를 열 수 있습니다. 왼쪽 **대화 설정 위의 목록**에서 **새 대화**를 누르면 하나 더 생기고, 이름을 눌러 오갑니다. 지금 보는 것을 한 번 더 누르면 이름을 바꾸고, **×** 로 닫습니다(최대 12개). 좁은 화면에서는 같은 목록이 가로로 놓입니다.
**각 대화창은 완전히 별개입니다** — 상대 역할·보낼 내용·요약·쓰던 입력까지 따로 기억하고, 서로의 내용을 참고하지 않습니다. 한 창에서 세계관을 상담하면서 다른 창에서 같은 재료로 평가를 받을 수 있습니다.
답을 기다리는 동안에도 다른 대화창을 읽고 쓸 수 있습니다. 기다리는 탭에는 점이 켜지고, 답이 오면 다른 창을 보고 있어도 보낸 창으로 들어갑니다. 그 창은 답이 올 때까지 닫을 수 없습니다.
다만 **보내기는 한 번에 하나만** 나갑니다 — 이 도구는 API 호출을 동시에 하나만 진행합니다. 앞선 답을 받는 동안 다른 창에서 보내면 기다려 달라고 알립니다.
대화창 묶음은 작업(작업 과정)마다 따로 보관됩니다.

981px 이상에서는 왼쪽 설정, 오른쪽 채팅을 배치하고 입력창은 화면 안에 유지합니다. 설정과 대화 기록만 각각 스크롤합니다. 980px 이하에서는 위쪽 **대화 설정**을 기본으로 접고 필요할 때 펼칩니다. **결론을 작업대에 반영·대화 요약**은 토큰 정보 오른쪽에 있으며, 좁은 화면에서는 다음 줄 오른쪽으로 내려갑니다.

입력칸과 보내기는 기본 48px 높이입니다. 입력칸은 내용에 맞춰 자동으로 늘어나고, 긴 글은 내부에서 스크롤합니다. 보내기는 같은 테두리 안의 오른쪽 아래에 유지됩니다.

- **상대 역할** — 세계관 상담역 / 인물 상담역 / 프롬프트 상담역 / 냉정한 평가자 / 역할 없음
- 분류를 바꾸면 상담역은 따라 바뀝니다. **평가자와 역할 없음은 그대로 둡니다**
- **역할 프롬프트 편집** — 역할에게 내릴 지시문을 직접 쓸 수 있습니다. 기본 프롬프트를 펼쳐 보고, 언제든 되돌립니다
- **보낼 내용** — 작업 재료 · 정리한 내용 · 지금 만든 것을 각각 켜고 끕니다. 작업 재료 안에서는 개별 재료와 로어북 항목을 고릅니다
- **눈 버튼** — 질문과 이어진 답변을 한 묶음으로 다음 전송에서 제외하거나 다시 포함합니다. 제외한 내용은 화면에 남고 상태도 저장됩니다. 대화 요약 자체도 별도로 제외할 수 있습니다
- **대화 요약 / 작업대 반영 / 보내는 대화 재료로** — 전송에 포함한 내용만 사용합니다. 요약할 때 제외한 문답과 요약은 삭제하지 않고 보존합니다. **대화 전체 복사**는 제외한 내용도 복사합니다

Ctrl+Enter로 보냅니다. 전송에 실패하거나 요청을 중지해도 보낸 문장은 대화에 남고 **다시 보내기 / 삭제**를 선택할 수 있습니다. 실패한 메시지를 처리하기 전에는 새 메시지를 보내지 않으며, 새로 작성 중인 입력은 보관합니다. 작성 중인 입력도 새로고침 뒤 복원되고, 응답 중에 전송을 반복해도 중복 호출하지 않습니다.

작업대의 완성 결과는 모든 칸을 한꺼번에 길게 나열하지 않습니다. 각 칸을 제목과 한 줄 미리보기가 있는 접이식 카드로 표시하고 첫 카드만 먼저 엽니다. 필요한 카드만 펼쳐 읽고 수정할 수 있으며 **모두 펼치기 / 모두 접기**도 지원합니다. 팝업을 여러 개 띄우지 않아서 카드끼리 비교하거나 모바일에서 위아래로 읽기 쉽습니다.

## 프롬프트 고치기

맨 윗줄 오른쪽의 **양식**에서 각 공정의 지시문과 출력 칸을 직접 고칩니다.
`{{이름}}` 자리는 실행할 때 값으로 바뀝니다. 쓸 수 있는 값은 맨 아래에 적혀 있습니다.

**출력 칸**에 적은 것이 곧 결과의 칸이자 잠금·다시 쓰기 단위입니다. 칸을 늘리거나 지우면 프롬프트가 알아서 따라갑니다.

**공통 지시문**은 모든 공정 맨 앞에 순서대로 들어갑니다. 구획별로 껐다 켤 수 있습니다.

SillyTavern 챗컴플리션 프리셋은 양식 줄 오른쪽의 **가져오기** 단추로 읽어들입니다(Orrery 양식 파일과 자동 판별).
지시문 블록만 뽑아 **공통 지시문**으로 들어오는 방식이라, 공정 자체는 그대로 남습니다.

## 연결 설정

연결 화면은 업체·키·모델을 먼저 보여줍니다. 주소와 응답 길이 등은 **세부 연결 설정**에서 조정하며, 로컬·사용자 지정 연결에서는 이 설정을 처음부터 펼칩니다. 연결별 값을 비워두면 양식에 적힌 값을 씁니다.

| 항목 | 설명 |
|---|---|
| 응답 토큰 상한 | 한 번에 받을 최대 길이. 끊기면 자동 이어받기와 결과 아래 **이어서 만들기**를 쓸 수 있으며, 자주 끊기면 이 값을 올리세요 |
| 컨텍스트 상한 | 모델이 받을 수 있는 총량. 넘으면 보내기 전에 막고 알려줍니다 |
| temperature | 낮추면 안정적, 올리면 변화가 큽니다 |
| top_p | 비워두면 보내지 않습니다 |

**모델 목록 받기**를 누르면 그 업체가 주는 모델 이름이 입력칸 후보로 채워집니다.
재료가 많아 상한을 넘으면 단계별 만들기의 **재료 정리**를 먼저 거치세요. 요약본으로 돌리면 분량이 크게 줄어듭니다.

화면의 **토큰쯤** 표시는 호출 전에 글자 수로 계산한 추정치입니다. 실제 호출 뒤 업체가 사용량을 보내 주면 로그와 연결 **확인** 결과에 정확한 입력·출력 토큰을 표시합니다. 확인 결과는 토스트로만 사라지지 않고 해당 연결 카드에 **마지막 확인 시각과 사용량**으로 계속 남습니다. 연결 주소·키·모델 같은 설정을 바꾸면 오래된 확인 결과는 자동으로 지워집니다. 사용량을 주지 않는 연결에서는 `토큰 사용량 미제공`으로 표시합니다.

**확인** 요청의 응답 토큰 상한은 24이며, 연결에 더 큰 응답 상한을 설정해도 확인 요청에는 적용하지 않습니다.

### API 연결만 옮기기

연결 화면에서 **API 연결 백업**을 누르면 API 키·액세스 토큰과 업체·모델·주소·연결 옵션을 JSON 파일로 내려받습니다. 다른 기기에서 **API 연결 불러오기**로 이 파일을 선택하면 됩니다. 키가 평문으로 포함되므로 본인만 접근할 수 있는 곳에 보관하세요.

불러온 연결은 현재 목록에 합쳐집니다. 같은 연결 id는 확인 후 갱신하고, 파일에 키가 없으면 기존 키를 유지합니다. 다른 연결과 현재 작업·재료·대화는 보존합니다. 불러오기 자체는 API를 호출하지 않습니다.

### 전체 백업

연결 화면의 **전체 백업**은 연결 주소·모델, 양식, 옵션, 성도 기록 전체를 항상 담습니다. 아래 항목은 백업 파일을 만들기 전에 골라 담습니다.

- 불러온 재료(즐겨찾기 상태와 폴더 구조 포함)
- 현재 작업과 중간 결과
- 대화 기록
- API 키·액세스 토큰 — 민감한 정보라 기본으로 제외되며, 본인만 보관할 파일에서 직접 켭니다

실행 로그는 백업에 넣지 않습니다. API 키가 포함된 파일은 다른 사람에게 보내지 마세요. **백업 불러오기**는 새 형식과 기존 `orrery-settings.json`을 모두 읽으며, 키를 제외한 백업을 불러와도 현재 연결의 키는 유지됩니다. 그 밖에 백업에서 제외된 항목도 현재 상태를 유지합니다.

현재 작업이 있는 상태에서 작업을 제외한 백업을 불러오면 해당 작업의 분류·양식·옵션을 유지합니다. 작업을 포함한 백업에는 이어쓰기·다시 쓰기 지시도 함께 저장됩니다. 잘못된 백업은 적용하지 않으며, 복원 도중 오류가 나면 기존 상태로 되돌립니다.

## 연결이 안 될 때

대부분의 연결은 파일에서 바로 열어도 됩니다.
특정 연결만 막힌다면 그 업체가 브라우저 직접 호출을 거부하는 것이니, OpenRouter처럼 다른 연결을 만들어 쓰세요.

여러 곳이 한꺼번에 막힌다면 이 파일이 있는 폴더에서 아래를 실행한 뒤
`http://localhost:8777/` 로 여세요.

```
python -m http.server 8777
```

## 알아둘 것

- API 키는 **이 브라우저에만** 저장됩니다. 공용 PC에서는 쓰지 마세요.
- 저장에 실패하면 화면에 경고를 계속 표시하고 **연결 → 전체 백업**을 안내합니다. 경고가 보이면 현재 작업을 백업 파일로 보관하세요.
- 브라우저 데이터를 지우면 보관함도 같이 지워집니다.
- 생성 도중 **Esc**를 누르면 멈춥니다.
